# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Stratos, please report it responsibly.

**Do not open a public issue.** Instead, email **security@stratos.dev** with:

- A description of the vulnerability
- Steps to reproduce
- The affected package(s) and version(s)

We will acknowledge your report within 48 hours and work with you to understand and address the issue before any public disclosure.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |

## Scope

This policy covers the following packages:

- `@stratosapp/core`
- `@stratosapp/ui`
- `@stratosapp/desktop`
